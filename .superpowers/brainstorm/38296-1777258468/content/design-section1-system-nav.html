Global Responsive System + Navigation

Breakpoints, spacing token overrides, and the hamburger nav — the shared infrastructure every page inherits.

Breakpoints

Phone
< 480px
iPhone 14 (390px), SE (375px). Primary mobile target. Single column everything.
Tablet
480–768px
Foldables, small tablets. Some 2-col layouts allowed where content density warrants.
Desktop
768–1024px
Laptops. Current desktop layout mostly intact, minor padding adjustments.
Wide
> 1024px
Current site exactly as built. No changes at this range.

Responsive Spacing Token Overrides (styles.scss)

--page-px
40px desktop → 16px mobile
--section-py
72px desktop → 48px mobile
--hero-pt
100px desktop → 50px mobile
--nav-height
64px desktop → 52px mobile
--grid-cols
2fr desktop → 1fr mobile
--card-gap
16–32px desktop → 12px mobile

UX Compliance (UI/UX Pro Max)

👆
Touch Targets
44 × 44px
Hamburger button, drawer links, CTA — all meet Apple HIG minimum.
⚡
Tap Delay
0ms
touch-action: manipulation on all interactive elements eliminates 300ms delay.
♿
Accessibility
WCAG AA
aria-expanded on hamburger, aria-label, focus trap in open drawer, Escape key closes.
🎨
Contrast
4.5 : 1
All text passes. Drawer links use rgba(255,248,240,0.55) → bumped to 0.7 for mobile.
🎭
Animation
250ms
Drawer slides in with ease-out. Scrim fades in parallel. Respects prefers-reduced-motion.
📏
Drawer Width
80vw max
Never full-screen. Leaves 20% visible so user sees they're still on the same page.
